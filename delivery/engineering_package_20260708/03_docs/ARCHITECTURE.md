# 架构文档

## 系统概述

乡村守护者是一款面向农村空巢老人的智慧养老平台，采用前后端分离架构，支持多角色协同管理。

## 性能优化策略

### 前端优化

1. **路由懒加载**
   - 使用 `defineAsyncComponent` 异步加载页面组件
   - 减少首屏加载时间

2. **状态管理**
   - 使用 Pinia 进行全局状态管理
   - 避免重复请求

3. **HTTP 缓存**
   - Axios 拦截器实现请求缓存
   - 避免重复请求

### 后端优化

1. **数据库索引**
   - 为高频查询字段添加索引
   - 定期执行 ANALYZE 和 VACUUM

2. **响应压缩**
   - 启用 gzip 压缩
   - 减少网络传输

3. **分页查询**
   - 所有列表接口强制分页
   - 限制单次返回数据量

## 扩展性设计

### 插件化架构

外部服务（AI、语音、地图）采用插件化设计：

```javascript
// 服务配置存储在数据库
const config = await db.get('SELECT * FROM system_config WHERE config_group = ?', ['ai']);

// 调用时动态加载
const result = await callAIService(config);
```

- `/api/report` - 设备数据上报
- `/api/notify` - 第三方通知回调
- `/api/export` - 数据导出接口
